# Manuel de Jesús Cardoza Cardoza — Backend Developer

# Profile

I am Manuel Cardoza, a Systems and Computer Engineer (Universidad Dr. Andrés Bello, Chalatenango,
2023) and backend developer. Most of my work has been on banking projects: microservices with
Java and Spring Boot, integrations with the core banking system on IBM AS400, and cloud
deployments on Azure, AWS and GCP.

I turn business problems into technical flows and into software running in production. My
foundation is the backend (Java and the Spring ecosystem), and I also work on the frontend with
Angular, React and Vue.js. I have more than four years of experience in banking systems
architecture, with agile methodologies (Scrum, Kanban) and tools such as Azure DevOps, Jira and
Jenkins.
